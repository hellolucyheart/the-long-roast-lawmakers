One original satirical sentence (212 characters) roasting lawmakers who regulate AI, crypto and the internet but cannot convert a file to PDF, written by `main.py` to `/output/entry.txt` for make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert" bounty. The line is fixed and polished in advance, so the program is fully deterministic: run it twice and the artifact is byte-identical. No network, no secrets, no model call at run time.

The roast:

> Lawmakers writing 400 pages of rules for artificial intelligence, crypto, and the internet just asked an intern to convert their bill to PDF — by printing it, scanning it, and emailing a photograph of the screen.

## Run it

```sh
python3 main.py
```

This writes the single roast line (212 characters, one line) to `/output/entry.txt` and prints it to stdout.
